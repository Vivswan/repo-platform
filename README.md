# repo-platform build branch

This branch is GENERATED by the build-branches workflow on `main` - do not
commit to it or open pull requests against it (they are closed automatically).
Template sources live in `templates/` on `main`.

`template` is rebuilt from each `main` commit whose CI run succeeds (the
branch ships only green main commits).

Consume with copier, e.g.:

    copier copy gh:Vivswan/repo-platform . --vcs-ref template

The composite actions the generated workflows call ship on the sibling
`actions` branch (green-gated the same way; its tree carries no jinja
filenames, so `@actions` refs extract cleanly on the runner).
